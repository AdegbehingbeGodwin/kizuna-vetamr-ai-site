# VetAMR-AI

Veterinary antibiotic reference data, formulation extraction, and antimicrobial
use analysis in a browser workspace.

This repository contains the static website distribution. Search and filter the
catalog, explore its composition, and inspect the included extraction and AMU
examples. Arbitrary document processing, uploads, and additional calculations
require the Python application. The website reports those requirements beside
the relevant actions.

Product records and classifications require source verification before use in
official reporting. Catalog frequency does not measure national consumption.

The site is published from the root of `main` using GitHub Pages.
